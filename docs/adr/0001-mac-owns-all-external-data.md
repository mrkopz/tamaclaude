# Mac ดึงข้อมูลภายนอกทั้งหมด board ไม่ต่ออินเทอร์เน็ต

เมื่อเพิ่ม page สำหรับหุ้น คริปโต อากาศ และปฏิทิน ข้อมูลทุกอย่างถูกดึงโดย daemon บน Mac แล้วส่งต่อ
ให้ board — board ยังคงไม่เปิดการเชื่อมต่อออกนอกวงแลนด้วยตัวเองเลยแม้แต่ครั้งเดียว เหตุผลหลักคือ
credential: Finnhub API key และสิทธิ์เข้าถึงปฏิทินเป็นของบัญชีผู้ใช้ ส่วน flash 4MB ของบอร์ดนี้
**ไม่ได้เข้ารหัส** การเก็บ token ไว้บนบอร์ดจึงเท่ากับแจก token ให้ใครก็ตามที่หยิบ
บอร์ดไปเสียบสาย USB — หลักเดียวกับที่ `sessionKey` ถูกบังคับให้อยู่บน Mac เท่านั้น เหตุผลรองคือ
บอร์ดนี้ไม่มี PSRAM และ LVGL กิน buffer ไปแล้ว 30KB การเพิ่ม TLS client กับ JSON parser หลายชนิด
เข้าไปคือการเบียดหน่วยความจำที่ยังไม่มีใครพิสูจน์ว่าเหลือพอ

## ผลที่ตามมา

Mac หลับ = ทุกตัวเลขบนทุก page แช่แข็ง นี่คือหนี้ที่ตั้งใจก่อ และถูกชดเชยด้วยการที่ทุก page
ต้องแสดง data age เสมอ (ดู ADR-0003) ราคาหุ้นเก่าที่ดูเหมือนสด
คือข้อมูลผิด ไม่ใช่แค่ข้อมูลเก่า
