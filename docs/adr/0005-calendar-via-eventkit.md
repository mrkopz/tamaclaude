# ปฏิทินอ่านผ่าน EventKit ของ macOS ไม่ใช่ Google Calendar API

page ปฏิทินอ่านนัดหมายจาก EventKit ซึ่งหมายความว่าผู้ใช้เพิ่มบัญชี Google ใน System Settings
ของ macOS เอง แล้ว TamaClaude อ่านสิ่งที่ระบบ sync มาให้ — แอปนี้จึงไม่ถือ credential ของปฏิทิน
แม้แต่ใบเดียว

เหตุผลที่ปฏิเสธการต่อ Google Calendar API ตรงๆ: TamaClaude เป็น open-source ที่แจกเป็น `.app`
เซ็นแบบ adhoc การฝัง OAuth client secret ลงไปคือการแจก secret ให้ทุกคนที่แกะไฟล์เป็น และ Google
บังคับให้แอปที่ขอ scope ปฏิทินผ่าน verification review ก่อน ไม่งั้นติดเพดานผู้ใช้และขึ้นจอเตือน
น่ากลัวตอนล็อกอิน — ต้นทุนที่ไม่สมเหตุสมผลสำหรับฟีเจอร์แสดงนัด 4 รายการบนจอ 2.8 นิ้ว
ทางเลือกที่สาม (ลิงก์ `.ics` ลับ) ถูกปฏิเสธเพราะมันคือ URL ที่ใครได้ไปก็อ่านปฏิทินได้ตลอดกาล
และเพิกถอนยาก

ผลพลอยได้: ปฏิทิน iCloud, Exchange และปฏิทินที่ subscribe ไว้ใช้ได้ฟรีโดยไม่ต้องเขียนอะไรเพิ่ม

## ผลที่ตามมา

ต้องขอสิทธิ์ TCC ปฏิทิน ซึ่งจะถามใหม่ทุกครั้งที่ rebuild เพราะ adhoc signature ทำให้ cdhash เปลี่ยน
— ปัญหาเดียวกับที่ Bluetooth เจอและโปรเจกต์นี้ยอมรับไปแล้ว และความสดของข้อมูลถูกจำกัดด้วยรอบ
sync ของ macOS ไม่ใช่รอบดึงของ daemon
