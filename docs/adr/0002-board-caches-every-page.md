# board เก็บข้อมูลทุก page ไว้ในหน่วยความจำ

หลักเดิมของโปรเจกต์คือ "firmware ไม่เก็บสถานะ วาดจากสิ่งที่ได้รับอย่างเดียว" รอบ multi-page
**จำกัดขอบเขตหลักนี้ให้แคบลง** เป็น "firmware ไม่มีตรรกะ แต่มี cache" — board เก็บ page frame
ล่าสุดของทุก page ไว้ และเป็นเจ้าของสองสิ่งที่ Mac ไม่มีทางรู้ได้เร็วพอ คือ active page และ
นาฬิกาของ page rotation กับ data age

ทางเลือกที่ปฏิเสธคือให้ Mac ส่งเฉพาะหน้าที่กำลังแสดง ซึ่งทำให้ swipe ต้องรอ round-trip (จอว่าง
ทุกครั้งที่ปัดนิ้ว) และที่แย่กว่านั้นคือเมื่อ BLE หลุดหรือ Mac หลับ การ swipe จะได้หน้าเปล่า ทั้งที่
ข้อมูลเมื่อ 20 นาทีที่แล้วยังมีประโยชน์อยู่มาก

## ผลที่ตามมา

board อาจอยู่ในสภาพ "ยังไม่เคยได้ข้อมูลของ page นี้เลย" ซึ่งต้องมีหน้าตาของมันเอง ห้ามวาดเป็น
จอเปล่าหรือโครงว่าง — หลักเดียวกับที่ `usage == nil` แปลว่า "ถอยไปเป็นนาฬิกาตั้งโต๊ะ" ไม่ใช่
"วาดโครงเปล่า"
