# PageKind เป็น enum ปิด ไม่ใช่ widget list ที่ส่งข้ามสาย

board รู้จักชนิดของ page แบบตายตัวและวาดแต่ละชนิดด้วยโค้ดของตัวเอง Mac ส่งไปแค่ *ข้อมูล*
(`temp`, `hi`, `lo`, รายการสัญลักษณ์กับราคา) ไม่เคยส่งพิกัด สี หรือขนาดฟอนต์ — `PageKind` จึงเป็น
สัญญากับ firmware แบบเดียวกับ `VisualState` และการเพิ่มชนิดใหม่ต้องแก้ Swift, C และ Python
พร้อมกัน แล้วแฟลชบอร์ด

ทางเลือกที่ปฏิเสธคือให้ page frame พก widget list ทั่วไป (`{x, y, text, size, color}`) ซึ่งจะเพิ่ม
ชนิดหน้าใหม่ได้โดยไม่ต้องแฟลช เหตุผลที่ปฏิเสธ: layout ทั้งโปรเจกต์มีแหล่งความจริงเดียวคือ
`tools/layout.toml` และลูปออกแบบจริงคือ `tools/preview.py` ถ้าพิกัดย้ายไปอยู่ในโค้ด Swift ที่ส่ง
ข้ามสาย หน้าใหม่ทุกหน้าจะออกแบบไม่ได้ด้วย preview อีกต่อไป เหลือแค่การแฟลชแล้วเพ่งจอ 2.8 นิ้ว
นอกจากนี้ widget list กินไบต์มากกว่าข้อมูลดิบหลายเท่าในงบ 500 ไบต์เท่าเดิม

## ผลที่ตามมา

การเพิ่ม page ชนิดใหม่แพงโดยตั้งใจ — ชนิดของหน้าไม่ควรงอกบ่อย ส่วนการเปลี่ยน *แหล่งข้อมูล*
ของหน้าที่มีอยู่ (เช่นเปลี่ยนผู้ให้บริการราคาหุ้น) ไม่ต้องแตะ firmware เลย
