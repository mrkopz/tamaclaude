# logo เหรียญเป็นบิตแมปเต็มสี — asset ชนิดที่สองของโปรเจกต์

ทุก asset ในโปรเจกต์นี้เคยเป็น rect list ชุดเดียว: มาสคอต prop ลูกศร sparkline ทั้งหมดคือรายการ
สี่เหลี่ยมในพิกัด unit ที่ `tools/gen/rects.py` กับ `firmware/main/ct_rects.c` วาดเหมือนกัน และ
`CLAUDE.md` เคยเขียนไว้ตรงๆ ว่า "no bitmaps, no sprite pipeline" **คำตัดสินนั้นถูกพลิกที่นี่**
เฉพาะกรณีเดียว: logo เหรียญบนหน้าคริปโต ซึ่งเก็บเป็นบิตแมป `LV_COLOR_FORMAT_RGB565A8` สองขนาด
(32px บนการ์ด 16px บนแถวเล็ก) generate จาก `tools/coins/*.svg` ด้วย `tools/export_coins.py`

เหตุผล: logo เหรียญไม่ใช่ของที่เราออกแบบ มันเป็นเครื่องหมายที่ผู้ใช้จำมาจากที่อื่น และความถูกต้อง
ของมันคือ *ความเหมือนต้นฉบับ* ไม่ใช่ความกลมกลืนกับจอ — ซึ่งกลับกันกับมาสคอตทุกชิ้นที่ผ่านมา

## ทางที่ปฏิเสธ

**rect list เหมือนของอื่นทั้งโปรเจกต์** — logo จริงไม่ได้ประกอบจากสี่เหลี่ยมแนวแกน ข้าวหลามตัดของ
ETH กับเส้นโค้งของ XRP ต้องถูกไล่เป็น run ทีละแถว ได้ ~50 rect ต่อเหรียญเพื่อผลลัพธ์ที่ยัง
ไม่เหมือนอยู่ดี

**mask สองสี (สีแบรนด์ + เจาะกลวง)** — เคยเป็นตัวเลือกนำ เพราะยังเดินผ่าน `ct_paint_rects` ได้และ
กินแฟลชหลักร้อยไบต์ ตกไปเพราะมันแก้ปัญหาไม่ครบ: logo คริปโตส่วนใหญ่คือจานกลม + glyph ข้างใน
สองสีทำให้แยก BTC จาก USDT ได้ แต่ยังห่างจาก "เหมือนต้นฉบับ" ซึ่งเป็นข้อกำหนดจริงของฟีเจอร์นี้

**ส่งบิตแมปมาบนสาย** — เหรียญใหม่ไม่ต้อง flash แลกกับไบต์บนเฟรมที่ `Wire.maxPayload` บีบจน
sparkline ถูกตัดทิ้งเป็นประจำอยู่แล้ว (ADR-0003) และต้องมี frame ชนิดใหม่ + cache บนบอร์ด
ซึ่งเป็นฟีเจอร์ทั้งก้อน ไม่ใช่ฟิลด์ที่เพิ่มเข้าไป · ผู้ใช้ยังเลือกเหรียญนอกชุดได้ตามปกติ มันแค่ได้
`_default.svg` เป็นรูป — ความสามารถที่แลกไปจึงเป็นศูนย์

**SVG เป็น input ของ build ฝั่งบอร์ด** — บอร์ดไม่มี decoder อะไรเลย และการเพิ่มเข้าไปแปลว่าจ่าย
RAM กับเวลากับโค้ดของ decoder เพื่อผลลัพธ์เดียวกับ raster ที่ทำครั้งเดียวตอน export

## ผลที่ตามมา

`tools/coins/*.svg` เป็นต้นฉบับ · `firmware/main/ct_coins.{c,h}` กับ `tools/coins/png/*.png`
ถูกเขียนทับทุกครั้งที่ export — แก้มือแล้วหายรอบหน้า เหมือน `layout.h` และตารางไทย

สีถูกบีบเป็น RGB565 **ตอน raster** ไม่ใช่ตอนวาด PNG ที่คายออกมาจึงเป็นสีที่จอทำได้จริง และเป็นชุด
เดียวกับที่หน้าตั้งค่าบน Mac โชว์ (`CoinIconImage`) — หน้าตั้งค่าที่สวยกว่าจอคือหน้าตั้งค่าที่โกหก
เรื่องผลลัพธ์ ที่ยังต่างกันได้ราวหนึ่ง LSB คือคณิตของการผสมอัลฟา (PIL ผสมบน 8 บิต LVGL ผสมบน 565)

เพดาน 32 เหรียญบังคับที่ `export_coins.py` ทุกเหรียญกิน (32² + 16²) × 3 = 3,840 ไบต์เท่ากันเป๊ะ
จำนวนไฟล์จึงเป็นหน่วยที่ถูกต้องของงบแฟลช ไม่ใช่ตัวประมาณ — 32 เหรียญ = 123 KB บน partition
`factory` 3 MB

ตอนลิงก์หลุด logo ถูกผสมเข้าหาเทาด้วย `LV_STYLE_IMAGE_RECOLOR` ไม่ได้เก็บรูปเทาไว้อีกชุด และ
**ไม่ยุบเหลือสีเดียว** — จานกับ glyph ที่กลายเป็นสีเดียวกันแปลว่า BTC เหลือวงกลมทึบพอดีตอนที่ภาพ
นั้นค้างบนจอนานที่สุด

หน้าหุ้นจองช่องขนาดเท่ากันแต่ไม่วาดอะไรลงไป กติกา "สองหน้า watchlist ต้องตรงกันทุกคอลัมน์" จึงยัง
เป็นจริง และ logo บริษัทเติมทีหลังได้โดยไม่ต้องขยับพิกัดอะไรอีก
