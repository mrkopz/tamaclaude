# board ประกาศรายการ PageKind ที่รองรับ ไม่ใช่เลขเวอร์ชัน

ตอนเชื่อมต่อ board ส่ง `BoardEvent` ชนิดใหม่บอกว่ามันรู้จัก PageKind ใดบ้าง daemon ส่ง page frame
เฉพาะหน้าที่อยู่ในรายการนั้น และแอปแสดงให้ผู้ใช้เห็นว่าหน้าไหนปิดอยู่เพราะ firmware เก่า

เหตุผล: บอร์ดนี้ไม่มี OTA (`DESIGN.md`) ผู้ใช้ลาก `.app` ใหม่ทับได้ใน 5 วินาที แต่การแฟลชต้องหา
สาย USB กับ `idf.py` ฉะนั้นสภาพ "แอปใหม่ + firmware เก่า" ไม่ใช่กรณีขอบ แต่เป็นสภาพปกติ
ทางเลือกที่ปฏิเสธคือบังคับให้เวอร์ชันตรงกันแล้วไม่ยอมเชื่อมต่อ ซึ่งฆ่าหน้ามาสคอตที่ใช้งานได้ดีอยู่ทิ้งไป
ด้วย และการส่งไปเงียบๆ แล้วให้ firmware เก่าทิ้งเฟรมที่ไม่รู้จัก ซึ่งทำให้ผู้ใช้ swipe แล้วไม่มีอะไร
เกิดขึ้นโดยไม่รู้สาเหตุ

เลือกประกาศเป็น **ความสามารถ** ไม่ใช่เลขเวอร์ชัน เพราะ PageKind เป็น enum ปิด (ADR-0004) และ
firmware อาจแยกสายได้ — การให้ฝั่ง Mac แปลเลขเวอร์ชันเป็นรายการฟีเจอร์คือตารางที่เน่าทันทีที่มี
สายที่สอง

## ผลที่ตามมา

LAN greeting มี version byte อยู่แล้ว (`ct_lan.c`) ส่วนนี้ไม่ทดแทนกัน — version byte คุมรูปแบบเฟรม
บนสาย ส่วน capability คุมว่าเนื้อหาชนิดไหนส่งได้
